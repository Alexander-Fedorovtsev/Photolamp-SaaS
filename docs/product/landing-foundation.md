# Подготовка анимированного landing page

Этап 0 содержит аккуратный mobile-first shell и демонстрационные витрины.
Это предварительный просмотр, а не завершённый продающий лендинг.
Первичные требования остаются в `landing-page-spec.md` и `brand-messaging.md`.

## Компоненты и настройки

- `BrandHeader`: reusable бренд и город из публичного DTO организации.
- `LampScene`: лёгкий собственный SVG-placeholder домашнего интерьера;
  без людей, медицинских сцен и демонстрации применения устройства.
- `StorefrontPreview`: hero, будущие четыре шага, два явно отключённых канала заказа.
- `src/lib/tenant.ts`: strict контракт demo-DTO, соответствующий OpenAPI backend.
- `globals.css`: светлая палитра, sun/mint accent, responsive grid, focus-visible,
  skip-link, reduced-motion. Системный шрифт не требует внешней сети.

Реальные контакты, адрес, цены, отзывы, документы и обещания не придуманы.
Демо-страницы не индексируются. Метаданные и manifest присутствуют; включать
индексацию и LocalBusiness только с проверенными данными и разрешением tenant.
