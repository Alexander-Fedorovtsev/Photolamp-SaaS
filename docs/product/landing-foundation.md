# Landing page: этап 1

Главная `/` теперь показывает семейный сценарий аренды, а B2B-направление
платформы вынесено в нижний блок. `/r/{tenantSlug}` использует тот же
`RentalLanding` с брендом, городом и цветовой темой из проверенного публичного
DTO. Это по-прежнему демонстрация: реальных tenants, контактов и тарифов нет.

## Реализовано

- Sticky header, hero, четыре шага, преимущества, блок условий, FAQ,
  повторный CTA и footer. На mobile — нижняя панель с safe-area отступом.
- Собственный лёгкий SVG: курьер передаёт закрытый кейс семье дома;
  применение оборудования и лечебный результат не изображены.
- Мягкое движение солнца и растения, hover/press и scroll reveal.
  `prefers-reduced-motion` отключает движение; кнопка позволяет остановить
  анимацию. Контент не скрывается до JS или IntersectionObserver.
- FAQ на native `details/summary` работает клавиатурой и без JS.
- `RentalPlanner` позволяет выбрать срок и способ получения. Выбор локальный,
  никуда не отправляется и не подтверждает доступность. Без тарифов сумма
  отсутствует; обе кнопки оформления отключены. Телефон и персональные данные
  не запрашиваются. Это UI-блок будущего калькулятора, а не рабочая котировка.
- Метаданные обновлены; demo остаётся `noindex`. Нет вымышленных отзывов,
  документов, телефонов, цен, SMS, платежей или готового личного кабинета.

Системный шрифт, CSS и собственный SVG не требуют внешних сервисов или
тяжёлого animation runtime. Анимация текста не меняет прозрачность, чтобы
сохранять контраст во время движения.

## Проверка

`npm run lint`, `npm run format:check`, `npm run typecheck`, `npm test`,
`npm run build`, `npm run test:e2e` из `apps/web`.
Browser tests проходят на 320/430/1440 px: две независимые витрины,
отсутствие overflow, клавиатура/axe, планирование без вымышленной цены,
FAQ без JS, reduced-motion, pause и sticky CTA. Lighthouse измеряется на
локальной production-сборке; показатель не является замером реальной сети
пользователя. Docker/HTTPS/Basic Auth и CD продолжают проверяться в CI.

## Следующий этап

Tenant foundation: организации, memberships, авторизация и PostgreSQL RLS
с отдельной runtime-ролью и тестами изоляции. После этого — инвентарь и тарифы.
Включать оформление можно только после серверного availability → quote →
hold → order. Реальные контакты, состав комплекта, правила аренды и документы
добавляются после подтверждения владельцем конкретной организации.

## Результаты проверки этой версии

Локально: 19 unit-тестов, 24 browser-теста, lint/typecheck/format и production
build прошли. Lighthouse 13.5.0 (mobile, localhost, Chromium): performance 92,
accessibility 100, best practices 100; LCP 1.6 s, CLS 0, TBT 330 ms.
Отчёт относится к локальной среде, без серверной сети и Basic Auth.
