# Brand Messaging и тексты

## 1. Позиционирование

**Photolamp-SaaS** — это современный сервис, который помогает:

1. семьям — быстро и спокойно организовать аренду фотолампы домой;
2. арендодателям — управлять заказами, оборудованием и клиентами в одной SaaS-системе.

## 2. Ключевой оффер для конечного клиента

> Фотолампа домой — быстро, удобно и с понятным сервисом.

Альтернативы:
- Аренда фотолампы без лишнего стресса
- Оформите аренду онлайн или по телефону
- Всё для аренды фотолампы в одном сервисе

## 3. Ключевые преимущества для клиента

- Быстрое оформление
- Заказ онлайн или по телефону
- Понятные условия аренды
- Личный кабинет с продлением и возвратом
- Доставка и поддержка
- Спокойный, современный сервис

## 4. Hero copy

### Вариант 1
**H1:** Фотолампа домой — быстро, удобно и без лишнего стресса

**Subhead:** Оформите аренду онлайн или по телефону. Доставка, понятные условия и личный кабинет для продления и возврата.

### Вариант 2
**H1:** Аренда фотолампы с доставкой и удобным личным кабинетом

**Subhead:** Подтвердите телефон, выберите даты и получите всё необходимое с понятным сервисом и поддержкой оператора.

## 5. Блок “Как это работает”

1. Выберите даты аренды
2. Подтвердите номер телефона
3. Получите лампу домой
4. Продлите или оформите возврат онлайн

## 6. Блок “Почему выбирают нас”

- Оформление за несколько минут
- Можно заказать по телефону
- Напоминания и статусы без путаницы
- Прозрачная стоимость без скрытых шагов
- Удобный возврат и продление

## 7. Важные смысловые ограничения

Нельзя писать:
- «мы лечим»;
- «мы гарантируем выздоровление»;
- «самый эффективный способ лечения»;
- «заменяет врача».

Можно писать:
- аренда фотолампы домой;
- удобная организация процесса;
- сервис помогает оформить, получить, продлить и вернуть оборудование;
- использование по назначению врача;
- поддержка по организационным вопросам.

## 8. CTA copy

### Primary CTA
- Оформить аренду
- Рассчитать стоимость
- Начать оформление

### Secondary CTA
- Заказать по телефону
- Позвонить оператору
- Получить консультацию

## 9. Сообщение для SaaS-направления (будущий B2B раздел)

> Управляйте арендой оборудования в одной системе: сайт, телефонные заказы, календарь, сотрудники, уведомления и учёт оборудования.

Подзаголовок:
> Запустите собственный сервис аренды на готовой платформе без разработки с нуля.
