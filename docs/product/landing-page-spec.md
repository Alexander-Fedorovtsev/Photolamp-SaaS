# Спецификация главной страницы (Landing Page)

## 1. Цель страницы

Главная страница должна **продавать услугу аренды фотолампы домой** и одновременно презентовать платформу как современный, удобный и надёжный сервис.

Для пилотной витрины ключевой сценарий: 

- посетитель быстро понимает, что можно взять фотолампу домой;
- убеждается, что это удобно и безопасно;
- видит понятную стоимость и порядок действий;
- либо начинает онлайн-заказ,
- либо звонит оператору.

## 2. Тон и визуальный стиль

### Тон коммуникации
- тёплый;
- спокойный;
- поддерживающий;
- без давления;
- без запугивания;
- без агрессивной медицинской рекламы.

### Визуальный стиль
- мягкие формы;
- светлая палитра;
- тёплые жёлто-солнечные акценты;
- аккуратные голубые/бирюзовые оттенки доверия;
- дружелюбные мультяшные иллюстрации;
- современный clean UI;
- лёгкие микроанимации.

### Нельзя
- показывать пугающие медицинские сцены;
- делать «чудесное исцеление»;
- использовать формулировки, будто сервис назначает лечение;
- рисовать небезопасное применение прибора.

## 3. Главная креативная идея hero-блока

### Смысл
Показать простой и эмоционально понятный путь:

1. семья оформляет заказ;
2. курьер привозит фотолампу;
3. родители используют её дома по назначению врача;
4. семья чувствует спокойствие, ребёнок окружён заботой;
5. сервис помогает пройти этот этап проще.

### Формат анимации
Предпочтительно одна из стратегий:

1. **Rive/Lottie hero animation**;
2. CSS/SVG анимированная сцена;
3. набор из 3–4 сменяющихся иллюстративных состояний.

### Сцена hero
Слева — текст и CTA.
Справа — анимированная иллюстрация:

- мультяшные родители;
- курьер передаёт компактную фотолампу;
- затем лампа уже стоит дома;
- рядом спокойный интерьер;
- ребёнок в кроватке/люльке в мягком безопасном стилизованном виде;
- над сценой мягкие солнечные акценты, создающие ассоциацию фототерапии;
- финальный эмоциональный акцент — родители чувствуют облегчение и порядок.

### Что должен передавать финальный смысл
Не «ребёнок чудом исцелился», а:

- лечение организовано дома;
- семье стало спокойнее;
- процесс стал проще и удобнее;
- сервис снял организационный стресс.

## 4. Структура главной страницы

### 4.1. Sticky header
Содержимое:
- логотип;
- название сервиса;
- телефон;
- кнопка «Заказать звонок»;
- кнопка «Войти»;
- кнопка primary: «Оформить аренду».

На mobile:
- компактный header;
- фиксированная нижняя sticky CTA-панель: «Оформить» / «Позвонить».

### 4.2. Hero
**Заголовок:**
> Фотолампа домой — быстро, удобно и без лишнего стресса

**Подзаголовок:**
> Оформите аренду онлайн или по телефону. Доставка, понятные условия и личный кабинет для продления и возврата.

**CTA:**
- primary: «Оформить аренду»
- secondary: «Заказать по телефону»

**Дополнительные trust-бейджи:**
- Авторизация по SMS
- Доставка по городу
- Продление онлайн
- Поддержка оператора

### 4.3. Блок “Как это работает”
4 карточки с иконками и микроанимацией:
1. Выберите даты
2. Подтвердите телефон
3. Получите лампу домой
4. Пользуйтесь и продлите при необходимости

### 4.4. Блок “Почему это удобно”
Карточки преимуществ:
- оформление за несколько минут;
- есть вариант по телефону;
- прозрачная стоимость;
- личный кабинет с продлением и возвратом;
- напоминания без навязчивости;
- доставка или самовывоз.

### 4.5. Блок “Для кого сервис”
Не как медицинские показания, а как пользовательские сценарии:
- когда нужно быстро организовать аренду;
- когда удобнее получить оборудование домой;
- когда важно продлить без лишних звонков;
- когда хочется видеть статус заказа онлайн.

### 4.6. Калькулятор стоимости
UI-компонент:
- выбор города/филиала;
- выбор типа лампы;
- дата начала;
- количество дней;
- доставка / самовывоз;
- мгновенный расчёт стоимости.

Под калькулятором:
- кнопка «Продолжить оформление»;
- ссылка «Предпочитаете по телефону? Мы оформим за вас».

### 4.7. Блок “Как выглядит процесс дома”
Иллюстрации/карточки:
- курьер привёз;
- родитель получил инструкцию;
- оборудование дома;
- возврат или продление в пару нажатий.

Важно: без медицинских обещаний, без графиков билирубина и т.п. в hero-маркетинге.

### 4.8. Блок доверия
- понятные условия аренды;
- договор и политика конфиденциальности;
- инструкция по использованию;
- контакты и режим работы;
- отзывы (если будут доступны позже);
- FAQ.

### 4.9. FAQ
Примеры вопросов:
- Как оформить аренду?
- Можно ли заказать по телефону?
- Как продлить аренду?
- Как происходит возврат?
- Что входит в комплект?
- Как связаться с оператором?

### 4.10. Bottom CTA
Повтор ключевого оффера:

> Нужна фотолампа домой?
> Оформите аренду онлайн или позвоните нам — поможем быстро и спокойно.

Кнопки:
- Оформить аренду
- Позвонить

### 4.11. Footer
- контакты;
- документы;
- политика конфиденциальности;
- оферта;
- вход в личный кабинет;
- для партнёров / для арендодателей (будущий SaaS-раздел).

## 5. Анимации и motion design

### Основной принцип
Анимации должны **усиливать доверие и современность**, но не мешать конверсии и не перегружать страницу.

### Обязательные анимации
1. Hero-иллюстрация с мягким looping motion.
2. Hover / press состояния кнопок.
3. Плавное появление блоков при скролле.
4. Анимация шагов “Как это работает”.
5. Скелетоны при расчёте доступности/стоимости.

### Технические рекомендации
- Предпочтительно Framer Motion для UI-анимации.
- Для hero — Lottie/Rive, если есть ресурс на качественный asset.
- Учитывать `prefers-reduced-motion`.
- Анимации не должны ухудшать LCP/CLS.

## 6. Конверсионные требования

Главная страница должна поддерживать **два равноправных канала конверсии**:

1. онлайн-заказ;
2. звонок оператору.

### Главные CTA по всей странице
- Оформить аренду
- Позвонить
- Заказать звонок

### Вторичные CTA
- Посмотреть условия
- Рассчитать стоимость
- Войти в личный кабинет

## 7. UX и mobile-first требования

- Сначала проектировать mobile.
- Шрифт не мельче комфортного мобильного минимума.
- Кнопки достаточно крупные для касания.
- Телефон кликабелен.
- Sticky CTA снизу на мобильных.
- Все формы простые, без длинных простыней.
- Поля ввода максимально сокращены.

## 8. SEO и контент

Нужны:
- title;
- meta description;
- OpenGraph;
- schema.org для LocalBusiness/Organization при необходимости;
- чистый semantic HTML;
- индексируемые заголовки H1/H2/H3;
- контент для городских посадочных страниц в будущем.

## 9. Accessibility

- контраст текста;
- фокус-состояния;
- alt для иллюстраций;
- aria-label для CTA;
- клавиатурная доступность;
- reduced motion support.

## 10. Что именно должен сделать Codex

Codex должен:

1. Реализовать главную страницу в Next.js.
2. Сделать компонентную структуру, пригодную для white-label будущих арендодателей.
3. Создать placeholder assets/illustrations, если готовых изображений нет.
4. Реализовать анимации hero и scroll reveal.
5. Добавить калькулятор стоимости как конверсионный блок.
6. Добавить CTA на онлайн-заказ и на телефон.
7. Сохранить лёгкую и быструю загрузку страницы.
8. Заложить дальнейшее разделение между маркетинговым лендингом и tenant-витриной.
